## 💻 Hakkımda

Anadolu Üniversitesi Bilişim Teknolojileri Meslek Yüksekokulu'nda Backend Yazılım Geliştirme eğitimi almaktayım. Nesne yönelimli programlama, ilişkisel veritabanı mimarileri ve web tabanlı kurumsal uygulamalar üzerine çalışıyorum.

* 🎓 **Eğitim:** Anadolu Üniversitesi Bilişim Teknolojileri MYO *(Yüksek Onur / Onur Belgesi)*
* 🚀 **Odak Alanları:** C#, ASP.NET Core MVC, Entity Framework Core, MySQL ve dinamik SaaS arayüz mimarileri.
